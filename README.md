#点餐小程序说明：（2026.10.08版本）
（说明：该版本仅为Python练习用）
-->包含2个主要板块：

---->用户点餐模式（完整流程如下）
    -->展示菜单（询问是否点餐）
    -->确认点餐后进入点餐环节
    -->点餐完成之后订单的展示
    -->展示订单，并询问是否支付（支付环节为模拟支付）
    -->完成一次订单后，会自动保存到订单日志中

---->管理员模式
    -->菜品的添加
    -->菜品的删除
    -->菜品价格的修改
    -->菜单展示
    -->菜单的手动保存（有设置自动保存）
    -->菜单清空功能
    -->订单日志记录（仅展示订单，无查询功能）

---->项目附带文件
    -->'菜品数据.json'  -->显示菜单所需的菜品数据
    -->'订单日志.txt'   -->记录文本日志
    -->'订单日志.json'  -->json数据文件的备份，以后可能拓展业务需要
    -->'模拟菜单.txt'   -->提供参考菜品
